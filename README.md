# Assignment 1 – Personal Portfolio

## 📌 Project Description

This project is a responsive personal portfolio web application developed using React and Vite.  

The purpose of this assignment was to practice HTML, CSS, and JavaScript fundamentals while integrating AI-assisted development tools.  

The website includes sections for About Me, Experience, Projects, Skills, and Contact, along with interactive hover animations to enhance user experience.

---

## 🚀 Features

- About Me section with introduction and tagline
- Experience section with structured role breakdown
- Projects section with images and descriptions
- Skills section
- Contact form (front-end only)
- Interactive hover animations (micro-interactions)
- Responsive layout for desktop, tablet, and mobile

---

## 🛠️ Technologies Used

- React
- Vite
- JavaScript (ES6+)
- CSS (Flexbox)
- AI-assisted tools (ChatGPT)
